# فهرس قناة «البحث العلمي»

موقع ثابت يفهرس منشورات قناة تيليجرام [@al_bahth_al_ilmi](https://t.me/al_bahth_al_ilmi) بعناوين وتصنيفات، مع بحث.

- `data/posts.json` — الفهرس (العنوان، التصنيف، النوع، رقم المنشور). يمكن تعديل أي عنوان أو تصنيف يدويًا.
- `scripts/sync.mjs` — يجلب المنشورات الجديدة من صفحة القناة العامة.
- `.github/workflows/sync.yml` — يشغّل المزامنة كل 3 ساعات ويحفظ التغيير، فينشر Vercel التحديث تلقائيًا.

ملاحظة: المزامنة تعتمد على بقاء القناة **عامة** (t.me/s/al_bahth_al_ilmi).
